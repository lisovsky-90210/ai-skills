## Каталог

| Скилл | Назначение | Версия |

## Примеры

- [Резюме до обработки — PDF](skills/hh-resume-to-cv/examples/before.pdf).
- [Резюме до обработки — RTF](skills/hh-resume-to-cv/examples/before.rtf).
- [Резюме после обработки — HTML](skills/hh-resume-to-cv/examples/after.html): скачайте файл и откройте в браузере, чтобы посмотреть оформление и раскрываемые разделы.

## Использование

Каждый скилл находится в отдельной папке внутри skills/. Инструкция, ресурсы, примеры и условия использования приведены в папке соответствующего скилла. Поддержка формата SKILL.md и способ установки зависят от выбранного ИИ-агента.
