# HH Resume → HTML CV

Скилл для ИИ-агента: преобразует резюме выгруженное с HH.ru (HeadHunter) в автономный HTML-файл с аккуратной вёрсткой и раскрываемыми разделами. Скилл оформляет уже написанное резюме: сохраняет должности, даты, достижения и числовые показатели. Не сочиняет опыт и не переписывает содержание без отдельного запроса.

Готовое резюме удобно переслать в мессенджере как один HTML-файл: получатель скачивает его и открывает в браузере. Этот же файл можно разместить как онлайн-страницу и отправить рекрутеру ссылку — тогда резюме можно просмотреть без скачивания. Размещение страницы выполняется отдельно; сам скилл готовит файл.

## Пример до и после

Все данные кандидата, работодатели, программы курсов и достижения в примере вымышлены. Телефон — заглушка, почта использует домен example.com. Университет указан как элемент демонстрационного примера; это не сведения о реальном выпускнике.

- [До обработки: исходное резюме PDF](examples/before.pdf) — демонстрационный документ с вёрсткой по образцу экспорта HH, включая логотип; не официальный файл HeadHunter.
- [Дополнительная версия RTF](examples/before.rtf) — тот же текст с оформлением по образцу HH: логотипом, колонкой дат, серыми заголовками и плашками навыков.
- [После обработки: автономное HTML CV](examples/after.html) — готовый результат.

Скачайте HTML-файл и откройте в браузере. GitHub обычно показывает исходный код HTML, а не интерактивную страницу.

Логотип HH используется в исходном примере, чтобы обозначить формат, который преобразует скилл. Пример не является продуктом или рекомендацией HeadHunter.


## Что меняется

Скилл оптимизирует подачу информации: скрывает за раскрываемыми разделами менее важные для первого просмотра сведения, убирает дубли и оптимизирует вёрстку. Благодаря этому большие резюме занимают меньше места на экране, становятся компактнее и легче читаются: актуальный опыт остаётся на виду, а подробности можно открыть по необходимости.

Скрытие не означает удаление: ранний опыт и курсы сохраняются полностью и раскрываются перед печатью. Удаляются только предусмотренные правилами служебные блоки и повторы — например, повторное указание разрешения на работу в России при гражданстве России. Достижения и описания работы не сокращаются и не переписываются без запроса.

- Контакты и личные сведения размещаются в двух столбцах; на телефоне — друг под другом.
- Работы оформляются блоками: даты слева, компания, должность и описание справа.
- Ранний опыт и курсы сворачиваются в заметные секции с кнопками «Развернуть» / «Свернуть».
- Образование остаётся открытым. Перед печатью раскрываются все разделы.
- Убираются служебная фраза о предпочитаемом способе связи, блок специализаций, параметры занятости, формата работы и времени в пути, отдельный блок тегов навыков, логотип HH при его наличии.
- Упоминания технологий в опыте и компетенции в «Обо мне» сохраняются. Ограничения по переезду и командировкам остаются.

В демонстрации открыты два последних работодателя, а два ранних места и два курса свернуты. Все четыре места работы и оба курса остаются в файле полностью. Сроки работы в примере рассчитаны на ноябрь 2026 года.

## Как использовать

Поместите папку скилла в каталог навыков вашего ИИ-агента согласно его инструкции. Внутри должны остаться SKILL.md и assets/, а при передаче копии — также LICENSE и авторские уведомления. Примеры для работы скилла не обязательны.

Приложите экспорт резюме и попросите:

> Используй $hh-resume-to-cv. Преобразуй приложенное резюме в автономный HTML. Сохрани текст опыта, даты и достижения. Результат сохрани отдельным файлом.

Для последующих правок приложите текущий HTML и опишите изменение. Можно явно попросить оставить теги навыков или выбрать, какие места работы должны быть раскрыты.

## Форматы и ограничения

Инструкции предусматривают DOC, RTF, DOCX и PDF. Расширение .doc может скрывать RTF — агент должен проверить фактический формат. Для извлечения DOCX/PDF ему нужны соответствующие инструменты; для сканов может потребоваться OCR. Сам скилл — набор инструкций и ресурсов, а не самостоятельный конвертер.

В демонстрации текст PDF и дополнительной версии RTF сверен с итоговым HTML с учётом предусмотренных правилами удалений. Отдельная проверка DOCX, двоичного DOC и PDF-сканов в этот пример не входит. Наличие SKILL.md не гарантирует совместимость со всеми агентами.

Результат не использует CDN, внешние шрифты или трекеры. Контактные ссылки открываются только при переходе по ним. Сам скилл не публикует резюме в интернете. Обработка исходника происходит в среде выбранного вами ИИ-агента.
